Dynamic Programming Mathematical Formulation

Subproblem Definition:
Let DP[i] be the maximum profit obtainable from a compatible subset of the first i jobs sorted by finish time e_1 ≤ e_2 ≤ ... ≤ e_n.

Recurrence Relation:
DP[i] = max( DP[i - 1], profit[i] + DP[p(i)] )
where p(i) is the index of the latest job that completes before job i starts (found via binary search bisect in O(log N)).

Base Case:
DP[0] = 0

Backtracking Branch & Bound Pruning Logic

Decision State Tree:
For task k (in topological dependency order):

  • Branches 1..M: Assign to resource r ∈ R at earliest feasible start time.
  • Branch M+1: Exclude task k (mark as missed).

Branch & Bound Pruning Rule:
If CurrentProfit + ∑_{j=k}^N profit[j] ≤ BestProfitSoFar, prune the entire subtree immediately!

Backtracking Operation:
Upon return from recursion, restore resource time cursors and task attributes.

DAA Viva Preparation & Core Questions
Q1: What is Job Scheduling?

The computational problem of allocating time slots on resources to jobs while satisfying deadline, dependency, and skill constraints to maximize profit or minimize makespan.

Q2: Greedy vs Dynamic Programming?

Greedy makes irrevocable local choices (EDF) without looking ahead. DP breaks problems into overlapping subproblems, memorizing optimal solutions to make globally optimal choices.

Q3: DP vs Backtracking?

DP requires overlapping subproblems and optimal substructure (polynomial time). Backtracking explores a search tree with depth-first search, undoing decisions when dead ends or suboptimal branches occur.

Q4: Why is Backtracking Exponential?

Each of N jobs has (M+1) choices (assigned to one of M resources or excluded), producing a state tree of size O((M+1)^N). Branch & Bound bounds this search space.

Q5: Why Limit Backtracking Input?

Because exponential time 2^N or 4^N explodes for large N. While N=10 takes ~2 ms, N=30 would take years. Therefore, Backtracking is meant for small, critical combinatorial instances.

Q6: What is Big-O vs Measured Time?

Big-O describes the asymptotic upper bound on growth rate as N → ∞. Measured execution time is the actual clock time in milliseconds on hardware, influenced by constant factors and CPU cache.

🎓 30-Second Viva Summary of this Project

"Our project, Smart Job Scheduler, addresses multi-constraint job scheduling across workers. We implemented and benchmarked three foundational DAA paradigms: a Greedy algorithm using Earliest Deadline First (EDF) with topological sorting in O(N log N + N·M) time; a Dynamic Programming scheduler for the Weighted Job Scheduling Problem in O(M·N log N) time; and a Recursive Backtracking algorithm with Branch & Bound pruning in O((M+1)N) time. We demonstrate that while Backtracking guarantees the globally optimal schedule and profit, Greedy and DP provide polynomial-time heuristics essential for real-world large-scale scheduling."
